Cauldron & refining reference

Which Paths sit together

Every distinct pair of Paths in a pot is weighed, and the results are added up. One feud can undo four agreements.

Each has advantage over the other. Never put these in the same pot.

What that costs you

A brew or refinement starts at 50 harmony and adds every pair. Six Paths make fifteen pairs, so a set with no quarrels is +60 before skill is counted. Swapping one quiet pair for a mutual feud is a 26-point swing — roughly what thirty-five levels of Alchemy buys you.

Same-Path pairs count as zero. Repetition is paid for separately, by dominance.
